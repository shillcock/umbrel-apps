# Umbrel Community App Store

Custom apps for [Umbrel](https://umbrel.com).

## Adding this App Store

On your Umbrel, go to **App Store** → **⋯** → **Community App Stores** → **Add** and enter:

```
https://github.com/shillcock/umbrel-apps
```

## Available Apps

### Proton Bridge

Proton Mail IMAP/SMTP bridge, exposed to your Tailscale network.

- **App ID**: `proton-bridge`
- **Port**: 7685 (operator console). IMAP 1143 / SMTP 1025 on the Tailscale IP only.
